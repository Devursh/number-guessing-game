# Number Guessing Game

A number guessing game built with HTML, CSS, and JavaScript. The goal is to guess the randomly generated number between 1 and 100.

## Features
- Random number generation
- Feedback when a guess is too high or too low
- Checks input value for empty inputs, decimals, and not in-range guesses
- New Game button to restart
- Disables guessing controls after a correct answer
- Responsiveness in multiple devices and scales correctly
